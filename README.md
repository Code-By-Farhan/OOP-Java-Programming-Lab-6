# Java Programming Lab 6 — OOP Practice

Java exercises focused on early object-oriented programming concepts.

## Topics Practiced
- Classes and objects
- Methods
- Basic object-oriented design
- Simple classes such as `Cat` and `Dog`
- Problem-solving with Java

## Purpose
This repository represents the transition from basic Java programming into object-oriented programming. I am using these exercises to build fundamentals before working on larger Java projects.

## How to Run
1. Install a Java JDK.
2. Open the required `.java` file in an IDE or terminal.
3. Compile and run the class containing `main()`.

More advanced OOP concepts will be added as I learn them.
